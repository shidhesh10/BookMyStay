# 🏡 BookMyStay

BookMyStay is a full-stack web application inspired by Airbnb that enables users to explore and manage stay listings. Built with **Node.js**, **Express**, **MongoDB**, and **EJS**, this project demonstrates modern backend architecture and CRUD operations in a real-world context.

## 🚀 Features
- 🏠 Create, Read, Update, and Delete (CRUD) stay listings  
- 🌍 Dynamic EJS templates for interactive UI  
- 🗃️ MongoDB integration for real-time data management  
- ✏️ Form-based listing management (add/edit/delete)  
- 🧩 Scalable structure for future integrations like user authentication and booking system  

## 🛠️ Tech Stack
- **Frontend:** EJS, CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Version Control:** Git & GitHub
